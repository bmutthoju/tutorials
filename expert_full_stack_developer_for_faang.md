## 1️⃣ Data Structures & Algorithms (DSA) – FAANG Level

Even for full-stack roles, **FAANG coding rounds are heavily DSA-focused**.
Cover **both conceptual mastery + coding speed**.

### Core Topics

* **Arrays & Strings**

  * Sliding window, two pointers, prefix sums
* **Recursion & Backtracking**

  * Subsets, permutations, N-Queens
* **Hashing**

  * HashMap, HashSet, collision handling
* **Linked Lists**

  * Fast/slow pointers, reverse in-place
* **Stacks & Queues**

  * Monotonic stack/queue problems
* **Trees**

  * Binary tree traversal (DFS, BFS), diameter, serialization
* **Binary Search Trees**

  * Balanced BST, LCA, range queries
* **Heaps/Priority Queues**

  * Top-K problems, heapify
* **Graphs**

  * BFS, DFS, shortest path (Dijkstra, Bellman-Ford), Union-Find
* **Tries**

  * Word search, autocomplete
* **Dynamic Programming**

  * 1D, 2D DP, knapsack, LIS, matrix DP
* **Greedy Algorithms**

  * Interval scheduling, Huffman coding
* **Bit Manipulation**

  * XOR patterns, subsets generation
* **Math & Number Theory**

  * GCD, modular arithmetic, combinatorics

**Practice strategy**:

* LeetCode **Top 200 FAANG Questions** list
* Solve \~500 curated problems (covering all patterns)
* Aim for **O(log n) / O(n)** solutions in most cases

## 2️⃣ Java Backend Expertise

You need **deep expertise** in Java since FAANG backend rounds test **language internals + system building**.

### Java Core (Advanced)

* JVM internals (heap, stack, garbage collection, JIT compiler)
* Memory model & concurrency
* Java Collections Framework (internal workings: HashMap, ConcurrentHashMap)
* Generics & Reflection
* Functional programming (Streams, Lambdas)
* Exception handling best practices

### Concurrency & Multithreading

* Thread lifecycle & synchronization
* Locks, semaphores, latches, barriers
* Executors, ForkJoinPool
* CompletableFuture
* Parallel Streams
* Deadlock detection & prevention

### Backend Frameworks

* **Spring Boot**

  * REST APIs, request lifecycle
  * Exception handling, filters, interceptors
  * Profiles & configuration management
* **Spring MVC**

  * Controller-service-repo pattern
  * Request mapping and parameter binding
* **Spring Security**

  * JWT-based authentication
  * Role-based access control (RBAC)
* **Spring Data JPA**

  * Entity lifecycle, caching
  * Query optimization (N+1 problem, projections)

### Databases

* SQL: Joins, indexing, transactions, normalization
* PostgreSQL/MySQL internals
* NoSQL: MongoDB basics, when to use NoSQL
* Caching: Redis (LRU eviction, pub/sub)

## 3️⃣ Frontend Skills for Full-Stack

FAANG expects backend-heavy skill for full-stack, but **frontend depth still matters**.

### Core Frontend

* HTML5 (semantic tags, accessibility)
* CSS3 (flexbox, grid, responsive design)

### React (FAANG’s most common choice)

* React Router

## 4️⃣ Low-Level Design (LLD)

LLD rounds test **OOAD skills** in Java.

### Key Areas

* SOLID principles
* Design patterns (GoF)

  * Creational: Singleton, Factory, Abstract Factory, Builder, Prototype
  * Structural: Adapter, Decorator, Proxy, Bridge, Composite, Flyweight
  * Behavioral: Strategy, Observer, Command, State, Chain of Responsibility
* UML diagrams (class, sequence, activity)
* Common LLD problems:

  * Parking lot system
  * Splitwise
  * BookMyShow
  * Elevator system
  * Chess game

---

## 5️⃣ High-Level Design (HLD) / System Design

FAANG HLD rounds focus on **scalability, reliability, and trade-offs**.

### Must-Know Concepts

* Scalability principles
* Load balancing (Round-robin, least connections)
* Horizontal vs vertical scaling
* Caching strategies (write-through, write-back)
* Database sharding, replication, partitioning
* Message queues (Kafka, RabbitMQ)
* API Gateway & service discovery
* CAP theorem, PACELC
* Rate limiting
* Consistent hashing
* CQRS & Event Sourcing

### HLD Practice Systems

* URL shortener
* Instagram/WhatsApp backend
* Netflix-like streaming service
* Uber/Lyft backend
* E-commerce system
