## NumPy
	1. Python library that provides support for large, multi-dimensional arrays and matrics
	2. Offers a large collection of high-level mathematical functions to operate on these arrays
	
ScipPi - scientific calculations

Why?

speed: NumPy is faster than regular Python lists (optimized on C and Fortran)
Functionality: A lot of built-in functions
	1. Linear algebra
		1. Eigenvalues
		2. Eigenvectors
		3. Matrix multiplication
		4. Inner products
		5. Cross products
Efficiency: Operations without having to use loops (vectorized operations)
